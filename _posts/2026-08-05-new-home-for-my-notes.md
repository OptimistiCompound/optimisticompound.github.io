I rebuilt this site to make technical writing easier to maintain and easier to find. It now uses the `al-folio` Jekyll starter, with content stored as Markdown and deployment handled automatically by GitHub Actions.

The plan is simple:

- write durable notes about systems, NLP, and large language models;
- document projects with enough context to be useful later;
- keep the site lightweight, reproducible, and version controlled.

Older notes remain available in my [Notion archive](https://quilted-lift-9d9.notion.site/Yong-Zhong-s-Blog-2997954e6e44800987f8f12a13143308). New writing will live here.
